# Release notes

## 0.2.0 — 2026-10-18

- Low/Med/High priorities with list colors; categories, tags, search, and combined Done/Pending/Late filters.
- Selected weekdays, weekdays/weekends, every N days or weeks, monthly repeats, inclusive end dates, and up to 12 independent reminder times per day.
- Native Done, Snooze 10 min / 1 hour / Tomorrow, and Edit notification actions. Snoozes survive restarts and midnight.
- Current/best scheduled-day streaks, weekly/monthly on-time percentages, per-task stats, and a month calendar with completion totals.
- Dark/Light/System appearance, a native StatusNotifier tray with Open/Pause/Resume/Quit, and a reusable editor window.
- Notification sound selection and optional offline eSpeak speech.
- JSON export/import with check-ins, CSV task export/import, manual SQLite backups, and 30 daily snapshots. Existing databases get a pre-upgrade backup and preserve check-in history.
- Markdown checklists with separate progress per reminder, a persistent single active timer, and optional focus windows and screen-lock check-in guards.
- Portable launcher installer and isolated scheduling, GUI, migration, desktop protocol, and lifecycle tests in CI.
